Clean replacement:
1. In GitHub Desktop choose Repository > Show in Explorer.
2. Delete everything inside the repository folder, but keep the hidden .git folder.
3. Extract this ZIP and open the ManuelTAi folder.
4. Copy everything inside ManuelTAi directly into the repository folder.
5. Refresh GitHub Desktop, commit, and push.

The repository root must directly contain app, .github, gradle, build.gradle, settings.gradle, gradlew, and gradlew.bat.

The sandbox validated XML parsing and Gradle configuration, but cannot perform a full Android compile because it has no Android SDK. GitHub Actions must perform the final API 34 compile, lint, tests, signing, and APK verification.
