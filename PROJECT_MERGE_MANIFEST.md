# ManuelTAi Complete Project Merge

This package contains the complete source and build configuration for the Android-only ManuelTAi application.

## Included

The package includes the Android app module, Kotlin source, XML layout, Android manifest, launcher icon, theme and string resources, Gradle wrapper, Gradle settings, Android build configuration, ProGuard configuration, GitHub Actions workflow, README, ignore rules, and this merge manifest. The local repository history contains the earlier MVP, SafeView-inspired restructure, duplicate-resource fix, Gradle wrapper fix, and installable test-signing fix.

## Deliberately not included

The package does not include `.gradle` caches, generated `build/` directories, downloaded dependency caches, or an APK. These files are generated by Gradle and GitHub Actions and should not be committed to a source repository. Excluding them keeps the project portable and prevents stale build output from causing resource conflicts.

The local-AI model is also not bundled yet. The current MVP contains the teacher workspace shell and local demo workflows; a quantized on-device model will be added after the Android build is stable.

## Build outputs

GitHub Actions generates:

```text
app/build/outputs/apk/debug/app-debug.apk
app/build/outputs/apk/release/app-release.apk
```

Both artifacts are test-installable. The release build currently uses the Android debug certificate for testing. A protected production keystore must replace that configuration before distribution.
